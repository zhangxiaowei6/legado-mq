# 墨栖阅读隐私政策

更新日期：2026-09-15

墨栖阅读是可在用户设备上运行的开源阅读工具。项目自身不运营账号系统、内容平台或用于存储书架数据的自有服务器。

## 数据处理

- **书架、书源、阅读进度与设置**：默认保存在设备本地。
- **网络访问**：只有在用户使用书源、RSS、图片、在线朗读、WebDAV、检查更新或其他联网功能时，应用才会向相应服务发起请求。目标服务可能看到 IP 地址、请求头以及用户主动提交的查询内容。
- **书源脚本**：用户导入的规则可以执行 JavaScript、设置 Cookie 或请求头并访问网络。书源属于不受墨栖阅读控制的用户配置，请只导入可信来源。
- **WebDAV**：同步和备份只连接用户自行配置的 WebDAV 服务。地址和凭据保存在设备配置中，并会发送给该服务用于认证。
- **分析服务**：墨栖阅读独立版不内置 Firebase Analytics、Firebase Performance 或其他由维护者运营的遥测服务。第三方书源、网页或用户选择的在线服务可能有自己的数据处理规则。
- **日志**：应用可按用户设置在本地记录运行日志、崩溃信息或堆转储。此类文件可能含设备与运行状态信息，只有用户主动导出或分享时才离开设备。
- **本地 Web 服务**：用户主动开启后，应用可在局域网提供书架和源管理接口。用户应仅在可信网络中使用，并自行保护设备和访问地址。

## 权限用途

- 存储和文件权限用于导入、读取、导出本地书籍及备份。
- 网络与网络状态权限用于用户配置的内容源、同步、更新及相关网络功能。
- 通知、前台服务、音频、电话状态等权限用于下载、朗读和在来电时暂停朗读等可选功能。
- 安装未知应用权限仅用于在用户确认下载更新后调起 Android 系统安装器；墨栖阅读不执行静默安装。

用户可以停用自动更新、WebDAV、日志和其他可选功能，也可以在 Android 系统设置中撤销权限。卸载应用通常会删除其本地私有数据；请先按需备份。
